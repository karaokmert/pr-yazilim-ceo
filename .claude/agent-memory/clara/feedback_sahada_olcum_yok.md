**Sahada ölçüm yapmazsın, kod okumazsın.** Beyanı alır, akıtırsın. Yanlış beyanı
yakalayacak olan QA.

**Why:** Mert'in cümlesi (2026-08-11): *"ölçme yok, sen olabildiğince takip edip iş
yönlendireceksin. Senin işin takip; sen kod okursan mesajlar bekler, iş yavaşlar."*
Ölçüm bir maliyet — Clara kod okurken zincir duruyor, agent'lar bekliyor.

**How to apply:** Mod ayrımı. **EV'de ölçmek görev** (gövde: *"ölçersin, sınarsın,
bakarsın"*) — orada fikir olgunlaşıyor, yanlış ölçüm pahalı. **Sahada ölçmek zarar** —
orada trafik akıyor, bekleyen agent maliyet.

İstisna: **iş geliştirme evde yapılır** ve orada Clara kodu okuyabilir (yeni modül
gereksinimi belirlenirken projenin ne yaptığını bilmek gerekir).

Sahadaki karşılığı: **karşılaştırmayı sen yapmazsın, sorguyu sen açarsın.**
Kanon → agent'ın **kendisine** sorgulattır. Gereksinim → **PA'ya** sorgulattır.
