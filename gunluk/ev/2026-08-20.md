
## VS Code Agents penceresi — Claude neden kilitli (ölçüm, 2026-08-20)

**Soru:** VS Code 1.133'ün Agents penceresinde Claude sağlayıcısı gri, "Upgrade to
GitHub Copilot Pro" diyor. Copilot almadan açılır mı?

**Ölçüldü (VS Code kaynak kodu, main dalı):**
Kilit `chat.agentHost.allowSignedOutWhenUsable` ayarında değil. O ayar tek başına
yetmiyor; `claudeAgent.ts` içindeki `_hasUsableNativeSetup()` şunu yapıyor:
ayar açık **VE** `detectExistingClaudeSetup()` true.

`detectExistingClaudeSetup()` kimliği YALNIZ üç yerde arıyor:
1. ortam değişkenleri (ANTHROPIC_API_KEY, ANTHROPIC_AUTH_TOKEN,
   ANTHROPIC_BASE_URL, CLAUDE_CODE_OAUTH_TOKEN)
2. `~/.claude/settings.json` → `env` bloğu (aynı dört anahtar)
3. aynı dosyanın `apiKeyHelper` alanı

**macOS Keychain'e BAKMIYOR.** Mert'in Claude Code oturumu Keychain'de olduğu için
VS Code kimliği göremiyor → harness "GitHub gerekiyor" diye ilan ediyor →
picker "UpgradeRequired" üretiyor.

**Anthropic eklentisi (anthropic.claude-code 2.1.236) ilgisiz.** package.json
`contributes` bloğu ölçüldü: yalnız configuration/commands/keybindings/views/menus.
`languageModels`, `chatSessions`, `enabledApiProposals` YOK. extension.js'te
"copilot" geçmiyor. Agent host'a hiçbir katkı sunmuyor — kurulu olması kilidi
etkilemiyor.

### ⚠️ ARIZA: `apiKeyHelper` terminalleri bozdu

Denendi ve geri alındı. Sebep mekanik: **`apiKeyHelper` VS Code'un değil
Claude Code'un kendi ayarı.** Konulduğunda Claude Code normal oturum kimliğini
bırakıp helper'ın döndürdüğü token'ı API anahtarı gibi kullanmaya çalışıyor →
tüm terminaller API error veriyor.

Yani araştırmanın önerdiği çözüm yan etki taşıyor. Betik silindi, settings.json
temiz, JSON geçerli.

**Ölçülmedi:** ayar konulduğunda Claude satırının gri mi kaldığı yoksa açılıp
"no models" mı dediği — terminaller bozulunca geri alındı, o ekran okunmadı.

### Maliyet karşılaştırması (karar verilmedi)
Copilot Pro $10/ay, 1.500 kredi, Claude Sonnet/Haiku var — **Opus yalnız Pro+
($39/ay) ve Max'te**. Mert şu an `opus[1m]` kullanıyor. Copilot'un Claude'u ayrı
cüzdan; mevcut Anthropic aboneliği o kotaya dokunmuyor → Claude'a ikinci kez ödeme.

**Keychain'deki oturum:** subscriptionType `max`, accessToken 108 karakter
(`sk-ant-oat01...`), expiresAt bugün 15:15 (kısa ömürlü, elle yazmak kırılgan).

## jcode (1jehuang/jcode) — incelendi, kurulmadı

**Ne:** Rust ile yazılmış bağımsız terminal coding agent'ı. Claude Code'un RAKİBİ,
VS Code eklentisi DEĞİL. MIT lisans, 18k yıldız, v0.77.1.

**Aradığımız şey değil — ölçüldü:** depoda Agent Host Protocol'e (AHP) dair
sıfır eşleşme. VS Code'un Agents penceresine bağlanmıyor, o pencereyi baypas edip
kendi TUI'sinde çalışıyor. Gri "Claude" kutusunu AÇMIYOR.

**İlginç yanı:** VS Code'un yapmadığını yapıyor — `security find-generic-password
-s "Claude Code-credentials"` ile Keychain'den Claude oturumunu okuyor
(`auth/claude.rs:800`). Yani Max aboneliğiyle API anahtarsız çalışmak mümkün;
VS Code bunu tercihen yapmıyor.

**Güvenlik — beklenenden temiz:**
- Claude token'ı yalnız `api.anthropic.com`'a gidiyor; yazarın sunucusuna giden
  yol bulunamadı
- Telemetri kodunda `access_token|refresh_token|api_key|keychain|bearer` → sıfır eşleşme
- Keychain okuması `native_source_allowed()` kapısının arkasında, varsayılan KAPALI
- auth.json 0o600 izinle yazılıyor, Keychain kaydı değiştirilmiyor
- postinstall/preinstall YOK, bağımlılıklar tanınmış crate'ler, installer SHA256 doğruluyor
- ⚠️ Kullanım telemetrisi varsayılan AÇIK (opt-out: `JCODE_NO_TELEMETRY=1`)
- ⚠️ Transcript paylaşımı varsayılan kapalı ama açılırsa TÜM konuşma + kaynak kod
  yazarın sunucusuna gider — müşteri kodunda asla açılmamalı
